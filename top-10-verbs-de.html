Die 10 Grundverben (Teil 1)

1. Sein (To Be)

Das Verb sein drückt Identität, Beruf, Herkunft, Zustand und Ort aus.

PronomenPräsensBeispiel
ichbinIch bin Student.
dubistBist du fertig?
er / sie / esistEr ist zu Hause.
wirsindWir sind glücklich.
ihrseidIhr seid pünktlich.
sie / SiesindSie sind sehr freundlich.
  • Identität & Beruf: 'Ich bin Paul', 'Sie ist Ärztin'.
  • Ort & Zustand: 'Wir sind in Berlin', 'Ich bin müde'.
  • Ausdrücke: 'pünktlich sein', 'bereit sein', 'einverstanden sein'.

2. Haben (To Have)

Das Verb haben drückt Besitz, Alter, Familie und Empfindungen aus.

PronomenPräsensBeispiel
ichhabeIch habe ein Auto.
duhastHast du Zeit?
er / sie / eshatSie hat zwei Brüder.
wirhabenWir haben eine Frage.
ihrhabtHabt ihr Hunger?
sie / SiehabenSie haben einen Hund.
  • Besitz & Alter: 'Ich habe ein Buch', 'Ich habe Zeit'.
  • Empfindungen: 'Ich habe Hunger', 'Ich habe Durst', 'Ich habe Angst'.
  • Ausdrücke: 'Lust haben', 'Recht haben', 'Zeit haben'.

3. Denken (To Think)

Das Verb denken drückt Meinungen, Überlegungen und Gedanken aus.

PronomenPräsensBeispiel
ichdenkeIch denke schon.
dudenkstWas denkst du?
er / sie / esdenktEr denkt an die Zukunft.
wirdenkenWir denken das Gleiche.
ihrdenktWas denkt ihr darüber?
sie / SiedenkenSie denken nach.
  • Meinung: 'Ich denke, das ist eine gute Idee'.
  • Gedanken: 'Ich denke an meine Familie'.
  • Ausdrücke: 'nachdenken über', 'denken an', 'anders denken'.

4. Wissen / Kennen (To Know)

Wissen nutzt man für Fakten und Wissen (ich weiß). Kennen nutzt man für Personen, Orte und Dinge.

PronomenWissenKennen
ichweißkenne
duweißtkennst
er / sie / esweißkennt
wirwissenkennen
ihrwisstkennt
sie / Siewissenkennen
  • Wissen (Fakten): 'Ich weiß die Antwort', 'Ich weiß, wo das ist'.
  • Kennen (Personen/Orte): 'Ich kenne Berlin', 'Kennst du diesen Mann?'.
  • Ausdrücke: 'Bescheid wissen', 'kennenlernen'.

5. Mögen / Gefallen (To Like)

Das Verb mögen und die Wendung gefallen drücken Vorlieben und Geschmack aus.

PronomenMögenBeispiel
ichmagIch mag Kaffee.
dumagstMagst du Musik?
er / sie / esmagEr mag Sport.
wirmögenWir mögen Reisen.
ihrmögtMögt ihr Schokolade?
sie / SiemögenSie mögen Filme.
  • Vorlieben: 'Ich mag Tee', 'Das gefällt mir sehr gut'.
  • Wunsch: 'ich möchte' (Höflicher Wunsch).
  • Ausdrücke: 'gern haben', 'Gefallen finden'.

6. Wollen / Möchte (To Want / Would Like)

Wollen drückt festen Absicht aus. Möchte ist die höfliche Form für Wünsche.

PronomenWollenMöchte (Höflich)
ichwillmöchte
duwillstmöchtest
er / sie / eswillmöchte
wirwollenmöchten
ihrwolltmöchtet
sie / Siewollenmöchten
  • Fester Wille: 'Ich will Deutsch lernen'.
  • Höfliche Bitte: 'Ich möchte einen Kaffee, bitte'.
  • Ausdrücke: 'willkommen sein', 'was willst du damit sagen?'.

7. Gehen (To Go)

Das Verb gehen drückt Fortbewegung zu Fuß oder allgemeines Vorankommen aus.

PronomenPräsensBeispiel
ichgeheIch gehe nach Hause.
dugehstWohin gehst du?
er / sie / esgehtEr geht zur Arbeit.
wirgehenWir gehen ins Kino.
ihrgehtGeht ihr spazieren?
sie / SiegehenSie gehen einkaufen.
  • Bewegung: 'Ich gehe in die Schule', 'Wir gehen spazieren'.
  • Befinden: 'Wie geht es Ihnen? / Wie geht's?'.
  • Ausdrücke: 'spazieren gehen', 'einkaufen gehen'.

8. Können (To Can / Be able to)

Das Modalverb können drückt Fähigkeit, Möglichkeit oder Erlaubnis aus.

PronomenPräsensBeispiel
ichkannIch kann Deutsch sprechen.
dukannstKannst du mir helfen?
er / sie / eskannEr kann gut schwimmen.
wirkönnenWir können anfangen.
ihrkönntKönnt ihr kommen?
sie / SiekönnenSie können hier sitzen.
  • Fähigkeit: 'Ich kann Auto fahren', 'Kannst du Englisch?'.
  • Möglichkeit: 'Das kann sein', 'Wir können später sprechen'.
  • Ausdrücke: 'Kann sein', 'so gut ich kann'.

9. Essen (To Eat)

Das Verb essen wird für Mahlzeiten, Speisen und Ernährung verwendet.

PronomenPräsensBeispiel
ichesseIch esse einen Apfel.
duisstWas isst du gern?
er / sie / esisstEr isst zu Mittag.
wiressenWir essen zusammen.
ihresstEsst ihr Fleisch?
sie / SieessenSie essen im Restaurant.
Mahlzeiten: 'Ich esse Frühstück', 'Wir essen Brot'.
Vokalwechsel: Beachten Sie den Wechsel e → i (du isst, er isst).
Ausdrücke: 'Guten Appetit!', 'essen gehen'.

10. Trinken (To Drink)

Das Verb trinken drückt das Trinken von Getränken und Hydratation aus.

PronomenPräsensBeispiel
ichtrinkeIch trinke Wasser.
dutrinkstTrinkst du Kaffee?
er / sie / estrinktEr trinkt Tee.
wirtrinkenWir trinken Saft.
ihrtrinktWas trinkt ihr?
sie / SietrinkenSie trinken ein Glas Wasser.
  • Getränke: 'Ich trinke morgens Kaffee', 'Viel Wasser trinken'.
  • Geselligkeit: 'Möchten Sie etwas trinken?'.
  • Ausdrücke: 'Prost!', 'etwas zu trinken haben'.
