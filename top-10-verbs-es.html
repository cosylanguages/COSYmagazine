1. Ser / Estar (To Be)

En español, ser se usa para identidad, origen y profesión; estar para ubicación, estados temporales y emociones.

PronombreSerEstar
Yosoyestoy
Túeresestás
Él / Ella / Ud.esestá
Nosotros/-assomosestamos
Vosotros/-assoisestáis
Ellos / Ellas / Uds.sonestán
  • Ser: 'Soy estudiante', 'Es de España', 'Es interesante'.
  • Estar: 'Estoy en casa', '¿Cómo estás?', 'Está cansado'.
  • Expresiones: 'ser de acuerdo', 'estar listo', 'estar de vacaciones'.

2. Tener (To Have)

El verbo tener expresa posesión, edad, relaciones familiares y sensaciones físicas.

PronombrePresenteEjemplo
YotengoTengo un coche.
Tútienes¿Tienes tiempo?
Él / Ella / Ud.tieneTiene dos hermanos.
Nosotros/-astenemosTenemos una duda.
Vosotros/-astenéisTenéis razón.
Ellos / Ellas / Uds.tienenTienen un perro.
  • Posesión & Edad: 'Tengo un libro', 'Tengo 20 años'.
  • Sensaciones: 'Tengo hambre', 'Tengo sed', 'Tengo frío', 'Tengo calor'.
  • Expresiones: 'tener que' (obligación), 'tener ganas de', 'tener miedo'.

3. Pensar (To Think)

El verbo pensar expresa opiniones, reflexiones y planes futuros (pensar + infinitivo).

PronombrePresenteEjemplo
YopiensoPienso que sí.
Túpiensas¿Qué piensas tú?
Él / Ella / Ud.piensaPiensa viajar pronto.
Nosotros/-aspensamosPensamos en el futuro.
Vosotros/-aspensáis¿Qué pensáis hacer?
Ellos / Ellas / Uds.piensanPiensan lo mismo.
  • Opinión: 'Pienso que es una buena idea'.
  • Planes: 'Pienso ir al cine mañana'.
  • Expresiones: 'pensar en', 'pensar que', 'dar que pensar'.

4. Saber / Conocer (To Know)

Saber se usa para datos y habilidades (saber + infinitivo). Conocer para personas, lugares y cosas.

PronombreSaberConocer
Yoséconozco
Túsabesconoces
Él / Ella / Ud.sabeconoce
Nosotros/-assabemosconocemos
Vosotros/-assabéisconocéis
Ellos / Ellas / Uds.sabenconocen
  • Saber (Habilidad): 'Sé hablar español', 'Sé dónde está'.
  • Conocer (Lugar/Persona): 'Conozco Madrid', '¿Conoces a Juan?'.
  • Expresiones: 'a saber', 'dar a conocer', 'hacer saber'.

5. Gustar / Querer (To Like / Love)

El verbo gustar se usa con pronombres indirectos (me gusta). Querer para expresar cariño o deseos.

PronombreGustarQuerer
Me / Yogusta / gustanquiero
Te / Túgusta / gustanquieres
Le / Élgusta / gustanquiere
Nos / Nosotrosgusta / gustanqueremos
Os / Vosotrosgusta / gustanqueréis
Les / Ellosgusta / gustanquieren
  • Gustar: 'Me gusta el café', 'Me gustan los deportes'.
  • Querer: 'Quiero a mi familia', 'Quiero aprender más'.
  • Expresiones: 'me gustaría' (deseo cortés), 'si quieres'.

6. Querer / Quisiera (To Want / Would Like)

Para pedir cosas con amabilidad, se utiliza la forma quisiera o me gustaría.

PronombrePresenteCortesía
Yoquieroquisiera
Túquieresquisieras
Él / Ella / Ud.quierequisiera
Nosotros/-asqueremosquisiéramos
Vosotros/-asqueréisquisierais
Ellos / Ellas / Uds.quierenquisieran
  • Deseo directo: 'Quiero un vaso de agua'.
  • Petición cortés: 'Quisiera reservar una mesa, por favor'.
  • Expresiones: 'querer decir' (significar), 'sin querer'.

7. Ir / Futuro próximo (To Go)

El verbo ir indica movimiento hacia un lugar y forma el futuro próximo (ir + a + infinitivo).

PronombrePresenteEjemplo
YovoyVoy a trabajar / Voy a comer.
Túvas¿Vas a la casa?
Él / Ella / Ud.vaVa a la universidad.
Nosotros/-asvamosVamos al cine.
Vosotros/-asvais¿Adónde vais?
Ellos / Ellas / Uds.vanVan a estudiar.
  • Desplazamiento: 'Voy al parque', 'Vamos a España'.
  • Futuro próximo: 'Voy a llamar a mi madre', 'Va a llover'.
  • Expresiones: '¿Cómo va todo?', '¡Vamos!'.

8. Poder (To Can / Be able to)

El verbo modal poder expresa capacidad, posibilidad o permiso.

PronombrePresenteEjemplo
YopuedoPuedo ayudarte.
Túpuedes¿Puedes venir hoy?
Él / Ella / Ud.puedePuede entrar.
Nosotros/-aspodemosPodemos hacerlo.
Vosotros/-aspodéis¿Podéis repetir?
Ellos / Ellas / Uds.puedenPueden hablar español.
  • Capacidad & Posibilidad: 'Puedo conducir', '¿Puedo pasar?'.
  • Petición amable: '¿Puede hablar más despacio, por favor?'.
  • Expresiones: 'no poder más', 'si se puede'.

9. Comer (To Eat)

El verbo comer se refiere a las comidas diarias, alimentos y hábitos de nutrición.

PronombrePresenteEjemplo
YocomoComo una manzana.
Túcomes¿A qué hora comes?
Él / Ella / Ud.comeCome con su familia.
Nosotros/-ascomemosComemos juntos.
Vosotros/-ascoméisComéis muy sano.
Ellos / Ellas / Uds.comenComen en el restaurante.
  • Comidas: 'Como fruta por la mañana', 'Vamos a comer'.
  • Expresiones: '¡Buen provecho!', 'dar de comer', 'comer fuera'.

10. Beber / Tomar (To Drink)

Los verbos beber y tomar se usan para líquidos, bebidas y reuniones sociales.

PronombreBeberTomar
Yobebotomo
Túbebestomas
Él / Ella / Ud.bebetoma
Nosotros/-asbebemostomamos
Vosotros/-asbebéistomáis
Ellos / Ellas / Uds.bebentoman
  • Bebidas: 'Bebo agua todos los días', 'Tomo un café por la mañana'.
  • Social: '¿Quieres tomar algo?'.
  • Expresiones: 'dar a beber', 'tomar un refresco'.

Estructuras gramaticales para nivel A0–A1 / A2

• Oraciones simples: Sujeto + Verbo + Complemento. • Futuro próximo y modales: Uso de 'ir a + infinitivo' y 'poder/tener que'. • Conjugaciones: Consulta las tablas de tiempos verbales en COSYtools.
